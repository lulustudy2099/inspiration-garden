# 灵感花园 · 可分享版

一款可在 iPhone 浏览器使用并添加到主屏幕的灵感记录 App。包含花园、灵感列表、分类、文字、拍照/上传、语音、嫩芽→花苞→开花、十天后的枯萎与唤醒，以及 JSON 备份。

## 数据放在哪里

每位使用者的记录只存在自己设备上、该网站域名对应的浏览器 IndexedDB 中。网站没有账号、服务器数据库或跨设备同步。朋友访问同一地址，不会看见你的记录。换手机、换浏览器、清除网站数据或系统清理存储时，记录可能丢失；请在“灵感手记”中定期**导出备份**，并妥善保管下载的 JSON（内含记录、照片及语音）。换设备时打开同一网站，点“导入备份”。浏览器隐私/无痕模式不适合长期保存。

## 免费发布到 GitHub Pages

1. 登录 GitHub，创建一个 **Public** 仓库，例如 `inspiration-garden`。不要在代码仓库中放自己的灵感备份 JSON。
2. 将本文件夹内的所有文件、`assets` 文件夹和 `.nojekyll` 上传到仓库根目录。可以在仓库页面用 **Add file → Upload files**，或用 Git 命令推送。
3. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 中选 **Deploy from a branch**；分支选 **main**，目录选 **/(root)**，然后保存。
4. 等待页面显示站点地址，通常是 `https://你的用户名.github.io/inspiration-garden/`。用 iPhone Safari 打开这个地址，点分享按钮 → **添加到主屏幕**。把地址发给朋友即可。

GitHub Pages 是静态托管；这里的全部交互在设备端运行。GitHub Pages 的访问速度和中国内地网络可达性因网络而异，发布后请用目标手机网络实际测试。

本地预览：在此目录执行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000/`。麦克风权限在公开网站 HTTPS 地址使用。

## 更新

修改文件后重新上传，等待 Pages 构建。已打开过网站的设备若还显示旧版本，可以完全关闭页面后再打开；如果修改离线缓存资源，递增 `sw.js` 中的 `CACHE` 版本号。
